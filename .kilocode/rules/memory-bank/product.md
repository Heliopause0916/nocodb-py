# NocoDB Python SDK 产品描述

## 项目存在的意义
NocoDB Python SDK 旨在为Python开发者提供一个简单、高效的方式来与NocoDB开源智能电子表格和无代码平台进行交互。NocoDB本身是一个强大的数据库应用构建平台，但缺乏官方的Python客户端库。此SDK填补了这一空白，让Python开发者能够轻松集成NocoDB到他们的应用中。特别针对NocoDB API V2提供了全面的支持，覆盖元数据管理和数据操作两大模块。

## 解决的问题
1. **API集成复杂性**：NocoDB REST API的直接使用需要处理认证、错误处理、缓存等复杂逻辑
2. **类型安全缺失**：直接使用API缺乏类型提示，容易在开发过程中出现类型错误
3. **性能优化**：频繁的API调用可能导致性能问题，需要智能缓存机制
4. **部署模式差异**：自托管和云实例的API路径和功能存在差异，需要统一接口
5. **V2 API功能覆盖**：NocoDB V2 API提供了丰富的功能，需要统一的Python接口封装
6. **拷贝和序列化支持**：Python对象需要支持标准的拷贝和序列化操作

## 产品如何工作
### 核心工作流程
1. **初始化客户端**：通过基础URL和认证令牌创建客户端实例
2. **分层操作**：按照工作区→项目→表格→视图→列的层次结构进行操作
3. **智能缓存**：自动缓存API响应，减少重复请求
4. **错误处理**：统一的异常处理和重试机制，适应V2 API错误格式
5. **拷贝和序列化**：支持Python标准的拷贝和序列化操作，保持对象独立性

### V2 API功能支持

#### 数据操作模块（重点实现）
- **记录CRUD操作**：完整的记录创建、读取、更新、删除功能，支持批量操作
- **列类型验证系统**：20+种列类型的自动验证和转换，包括基础类型、选择类型、验证类型和特殊类型
- **特殊类型处理**：附件、链接记录、只读字段、系统字段的智能处理
- **记录统计**：统计表格或视图中的记录数量
- **链接记录管理**：支持多对多、一对多等关系链接
- **附件上传**：支持文件上传到存储系统
- **高级查询**：支持字段筛选、排序、分页、视图过滤

#### 验证器系统功能
- **多级验证**：支持STRUCTURAL（结构验证）和FULL（完整验证）两个级别
- **装饰器注册**：使用`@register_validator`装饰器简化验证器注册
- **类型安全**：基于NocoDBColumnType枚举实现类型安全验证
- **只读列处理**：自动识别并拒绝只读列的修改操作
- **统一接口**：所有验证器实现统一的validate、convert、normalize方法
- **全局验证函数**：提供`validate_value`全局函数，简化验证调用

##### 列分类与只读属性
基于对NocoDB列模型的深入分析，SDK识别出三类特殊列，这些列在记录操作中需要特殊处理：
- **系统列**：由NocoDB系统自动生成，值完全由系统控制（如Id、CreatedAt、UpdatedAt等），用户无法修改。
- **用户定义的值只读列**：由用户创建，但值由系统计算或生成（如Formula、QrCode、Button等），用户无法直接修改值。
- **链接列**：由用户创建Links列时，系统自动衍生的LinkToAnotherRecord列，值只读，必须通过专门的链接记录API管理关系。

SDK自动处理这些特殊列，在创建/更新记录时过滤只读字段，提供清晰的错误信息，并通过专用API管理链接关系。

#### 元数据管理模块
- **项目管理**：项目的CRUD操作，支持自托管和云实例
- **表格管理**：表格创建、元数据管理、更新和删除
- **视图管理**：网格视图、表单视图、画廊视图、看板视图
- **列操作**：列创建、更新、删除、主值设置
- **过滤器和排序**：视图级别的条件过滤和排序规则
- **数据源管理**：多数据源支持和管理
- **用户和权限**：项目用户管理和角色分配
- **评论系统**：行级别评论功能
- **Webhooks**：表钩子管理和事件触发
- **API令牌**：令牌创建和管理

#### 数据操作模块
- **记录CRUD操作**：完整的记录创建、读取、更新、删除功能
- **记录统计**：统计表格或视图中的记录数量
- **链接记录管理**：支持多对多、一对多等关系链接
- **附件上传**：支持文件上传到存储系统
- **高级查询**：支持字段筛选、排序、分页、视图过滤

### 拷贝和序列化支持
- **遵循简洁原则**：核心类实现`__copy__`、`__deepcopy__`、`__getstate__`、`__setstate__`方法
- **缓存状态管理**：拷贝时自动重置缓存状态，保持对象独立性
- **线程安全处理**：正确处理线程锁的序列化和反序列化
- **pickle兼容**：支持标准的Python序列化操作

### 用户体验目标
- **简单易用**：直观的API设计，减少学习成本
- **类型安全**：完整的类型提示，提供更好的开发体验
- **性能优异**：内置缓存机制，提升响应速度
- **灵活配置**：支持自定义超时、缓存时间等参数
- **功能全面**：覆盖NocoDB V2 API的所有主要功能
- **标准兼容**：支持Python标准的拷贝和序列化操作
