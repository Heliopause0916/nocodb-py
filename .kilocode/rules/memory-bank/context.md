# NocoDB Python SDK 项目上下文

## 当前工作重点
项目处于早期开发阶段，核心架构已经搭建完成，但功能尚未完善。基于最新获取的NocoDB API V2参考文档（Meta和数据操作），当前重点是扩展对V2 API的全面支持，包括元数据管理和数据操作两大模块。

## API V2功能发现
通过分析NocoDB API V2参考文档，发现了完整的API功能范围，分为两大模块：

### 元数据管理模块
- **项目管理**：完整的CRUD操作（列出、创建、获取、更新、删除项目），支持自托管和云实例
- **表格管理**：表格的创建、元数据获取、更新和删除
- **视图管理**：支持网格视图、表单视图、画廊视图、看板视图等多种视图类型
- **列操作**：列的创建、获取、更新、删除以及主值设置
- **过滤器和排序**：视图级别的过滤条件和排序规则管理
- **数据源管理**：多数据源的支持和管理
- **用户和权限**：项目用户管理和角色分配
- **评论系统**：行级别的评论功能
- **Webhooks**：表钩子管理和事件触发
- **API令牌**：令牌的创建和管理

### 数据操作模块
- **记录CRUD操作**：列出、创建、读取、更新、删除表格记录
- **记录统计**：统计表格或视图中的记录数量
- **链接记录管理**：列出、链接、取消链接记录
- **附件上传**：支持文件上传到存储系统

## 近期变化

## 下一步计划
1. **扩展V2 API支持**：优先实现项目管理、表格操作和视图管理等核心元数据功能
2. **实现数据操作**：增加对行数据的CRUD操作、链接记录和附件上传支持
3. **增强错误处理**：完善异常处理机制，适应V2 API的错误响应格式
4. **增加测试覆盖率**：编写更全面的单元测试和集成测试，覆盖V2 API端点
5. **文档完善**：更新API文档以反映完整的V2 API支持情况
6. **性能优化**：优化缓存策略，提高性能，支持大规模数据操作

## 当前状态
- 版本：0.0.0（早期开发）
- 支持的功能：工作区、项目、表格的基础查询操作（基于V1 API），包括项目创建功能
- **V2 API支持状态**：核心架构已就绪，但V2 API的具体功能（如项目管理CRUD、表格操作、视图管理等）尚未实现
- **新增模块**：已创建`column.py`文件框架，但列管理功能尚未实现
- 测试：基础测试框架已搭建，包含项目创建测试，但覆盖率有待提高
- 文档：已创建详细的API参考文档，README需要更新以包含完整的V2 API信息

## 已知问题
- 仅支持基础的查询操作和项目创建，缺少V2 API的完整元数据管理和数据操作功能
- 错误处理机制尚不完善，需要适应V2 API的错误响应格式
- 缓存机制需要进一步测试和优化，以支持V2 API的复杂数据结构
- 对云实例和自托管实例的差异处理需要加强，V2 API路径有所变化
- 需要增加对分页、过滤、排序、链接记录等高级功能的支持
- `column.py`模块为空，需要实现列管理功能
